# AURA Home v0.1 — безопасный прототип для Xiaomi L43M5-ES

Это **не прошивка**. APK запускается как обычное Android TV-приложение на Android 9.
* Не изменяет системные разделы или загрузчик.
* Не отключает заводской лаунчер PatchWall.
* Источники HDMI показываются **только если Android TV InputManager сообщает состояние CONNECTED**. Нет доступа к TV Input — не рисуем выдуманные HDMI.
* Действия по HDMI 2.0 и другим привилегированным режимам пока только информационные — без изменения драйверов.
* По кнопке MENU (три полоски) открывается контекст источника, если выделен активный HDMI.
* Поиск приложений работает локально, кнопка микрофона передаёт запрос имеющемуся обработчику голосового ввода Android. Если такого обработчика нет, работает текстовый поиск.
* На главном экране отображаются реальные установленные Android TV-приложения.
* Для полной AURA Firmware требуется **совместимый заводской образ** и протестированное восстановление.

## Важно: несовпадение идентификаторов
Наклейка устройства: L43M5-ES (Xiaomi Pro E43S), 2 GB / 32 GB.
ADB: MiTV-ANSP0, jobs, build 23.6.5.3226.
В публичном описании другая модель Xiaomi Mi TV 5 Pro 65 также использует MiTV-ANSP0/jobs и сборку 3226, но с 4 GB RAM. Прошивка от того ТВ **НЕ является доказанно совместимой**.

В первой версии источники не переключаются: TV InputManager не предоставляет непривилегированным приложениям универсальный способ выбора встроенного HDMI-источника Xiaomi. Режим HDMI 2.0 не меняется.
